# Admin Overview

这里只做行政材料的非敏感索引，帮助你知道“有什么、在哪、什么时候用”，不保存敏感扫描件内容。

## Candidate Areas

| Area | Examples | Handling |
|---|---|---|
| Identity | ID, passport, household registration | Metadata only |
| Education Proof | transcripts, degree certificate, enrollment verification | Metadata only |
| Finance | bank cards, tax or reimbursement records | Metadata only |
| Visa / Settlement | visa documents, 上海落户材料 | Metadata plus checklist |
| Employment | internship contracts, offers, certificates | Redacted summaries only |

## Rule

如果页面需要写入证件号、银行卡号、护照号、住址、合同金额、恢复码、API key，默认不要写。只写用途、保存位置、有效期、办理流程和注意事项。
