# LLM Leaderboard & Benchmark Resources

## Context

收集值得关注的 base LLM leaderboard / benchmark 追踪网站，方便快速查看当前 SOTA 格局。

## Resources

### llm-stats.com

- **URL**: https://llm-stats.com/benchmarks/humanity's-last-exam?tab=reviews
- **定位**: Base LLM leaderboard 网站，覆盖多个主流 benchmark
- **特点**:
  - 有 Humanity's Last Exam (HLE) 等高难度 benchmark 的排行
  - 支持 tab 切换（如 reviews 视图）
  - 适合快速纵览各家 base model 的相对位置
- **适用场景**: 了解当前 base model 能力边界、选 baseline 时参考

## Key Judgments

- HLE 作为 benchmark 难度极高，适合区分顶尖 base model 的细微差距
- llm-stats.com 的 reviews tab 提供了社区评价维度，比纯分数更立体

## Next Steps

- 持续关注 HLE 榜单变化，尤其是新模型发布后的排名变动
- 如有其他优质 leaderboard 网站，继续补充到本页
