# MLRC-Bench: Can Language Agents Solve ML Research Challenges?

**arXiv:** https://arxiv.org/abs/2504.09702
**OpenReview:** https://openreview.net/forum?id=t8Okk2PRWU

## Abstract
MLRC-Bench is a dynamic benchmark designed to rigorously assess how well language agents address ML research challenges with objective, performance-based evaluations.

## Key Contributions
- Dynamic benchmark (tasks can be updated as field evolves)
- Rigorous protocols with objective, performance-based metrics
- Focuses on ML research competition-style challenges
- Highlights significant challenges and misalignment in current agents

## Distinction from MLR-Bench
| | MLR-Bench | MLRC-Bench |
|--|-----------|------------|
| Tasks | 201 open-ended research tasks | Competition-style challenges |
| Evaluation | LLM judge (MLR-Judge) | Objective performance metrics |
| Focus | Full research pipeline | Solving specific research problems |
| Dynamic | Static | Dynamic (updatable) |

## Key Findings
- Significant challenges remain for current language agents
- Misalignment between agent behavior and what good research requires
- Objective metrics reveal gaps that subjective evaluation might miss
