# Phase 3 Failed

The original proposal had a structural deficiency: it remained observationally close to ordinary effect-aware fusion/delegate packaging, bypassed C13's required relation-typed propagation, provided no isolated ablations for the structural/decomposition composition, and evaluated only one model on one board, which cannot support a general FPGA-backbone title.

The one permitted rewrite still fails falsification review. Its pre-synthesis removable-control-time estimate, `C_R`, cannot separately measure the launch/wait cost of a region that has not yet been built or the seal-analysis cost. The proposed controls do not cleanly isolate decomposition from RTECC admission while holding artifact execution constant. The 30-pair bootstrap rule also omits a reproducible estimand and interval procedure sufficient to establish a greater-than-10% effect. Correctness and strictness failures properly override speed, but that priority does not repair these causal and statistical deficiencies.

No reviewer-defensible idea card is emitted.

## Evidence Required Before Rerunning Idea Spark

- Measured, separately instrumented region launch, region wait, and seal-analysis costs from an implemented prototype or equivalent calibrated hardware path; a pre-synthesis aggregate estimate is insufficient.
- Isolated controls for decomposition-off and RTECC-off conditions that hold the same artifact and execution path constant, plus an ordinary effect-aware fused-region/delegate baseline.
- A genuine C13 mechanism with relation-typed propagation producing a named admission-controlling closure certificate, or a remapping to a structural pattern whose signature operation is verified region substitution.
- A fully specified paired statistical protocol: exact percentage-reduction estimand, bootstrap construction, resample count, random seed policy, confidence level, multiplicity handling, and a lower confidence bound exceeding 10%.
- Validation across enough models and FPGA boards to support a general title, or a title and claim explicitly scoped to the single tested model/U280 configuration.
- Retained correctness, strictness, timeout, quarantine, and fault-injection gates, all of which must pass before any speed result is considered.
