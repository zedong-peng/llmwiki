\section{Conclusions}
We introduce \ours, an evaluation gym for agent memory with curated multi-session tasks featuring interdependent subtasks, designed to assess whether memory can effectively support agent decision-making within a memory–agent–environment execution loop. Moving beyond recall-based memory benchmarks and single-session agent evaluations, \ours treats memory as a functional component of agentic tasks. Empirically, state-of-the-art agent memory methods achieve low success rates in \ours, revealing persistent challenges in maintaining and reusing memory across interdependent sessions and underscoring the need for testbeds that evaluate memory as a functionally coherent component of LLM agents.
