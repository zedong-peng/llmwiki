\begin{abstract}
  % Memory is a core component of LLM agents. 
  Existing evaluations of agents with memory typically assess \textit{memorization} and \textit{action} in isolation. 
  One class of benchmarks evaluates memorization by testing recall of past conversations or text but fails to capture how memory is used to guide future decisions. Another class focuses on agent acting in single-session tasks without the need for long-term memory.
  However, in realistic settings, memorization and action are tightly coupled: agents acquire memory while interacting with the environment, and subsequently rely on that memory to solve future tasks. To capture this setting,
  We introduce \ours, a unified evaluation gym for benchmarking agent memory in \textit{multi-session Memory-Agent-Environment loops}. 
  The benchmark consists of human-crafted agentic tasks with explicitly interdependent subtasks, 
  where agents must learn from earlier actions and feedback by distilling experiences into memory, and subsequently use that memory to guide later actions to solve the overall task.
  \ours supports evaluation across web navigation, preference-constrained planning, progressive information searching, and sequential formal reasoning, and reveals that agents with near-saturated performance on existing long-context memory benchmarks like LoCoMo perform poorly in our agentic setting, exposing a gap in current evaluations for agents with memory. 
  \ours is released at \url{https://memoryarena.github.io/}.

  
  %Existing evaluations on agents with memory usually isolately evaluate agent's \textit{memorization} and \textit{execution}: memory benchmarks focus on answering questions or summarizing a piece of information hidden in long-context conversations, which do not adequately capture the function of memory in decision-making agentic settings, and agent benchmarks are typically limited to single-session tasks where persistent long-term memory is not causally required. We introduce \ours, a unified evaluation gym for benchmarking the role of memory in agents in \textbf{multi-session memory–action–environment loops}. The benchmark consists of human-crafted agentic tasks with interdependent subtasks, where later decisions are underspecified unless memory correctly tracks and reuses task-relevant information from earlier traces. \ours supports unified evaluation across domains, including web navigation, preference-constrained planning, compositional information searching, and sequential formal reasoning. Empirical results in \ours show that agents achieving saturated performance on existing long-context memory benchmarks exhibit low success rates in multi-session agentic tasks, highlighting the role of \ours to fill in the gap between current evaluation and effective memory usage in agentic settings.
  
  
\end{abstract}
