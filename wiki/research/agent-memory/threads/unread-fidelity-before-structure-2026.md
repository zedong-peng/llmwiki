# Fidelity Before Structure: Verbatim Chunks Beat Lossy Artifact Extraction in Long-Conversation LLM Memory

## Paper Meta
- Title: Fidelity Before Structure: Verbatim Chunks Beat Lossy Artifact Extraction in Long-Conversation LLM Memory
- Year: 2026
- Venue: Arxiv
- arXiv: https://arxiv.org/abs/2601.00821

## TL;DR
- Cleanest controlled evidence for verbatim storage: holds retriever, reranker, and judge constant while comparing typed extracted artifacts vs verbatim conversation chunks.
- Verbatim wins by 15.9 accuracy points on LoCoMo (43.9 vs 28.0) and 22.0 points on LongMemEval-S (67.4 vs 45.4); artifact-union does not close the gap.
- Conclusion is deliberately narrow: structure should augment verbatim evidence, not replace it.
