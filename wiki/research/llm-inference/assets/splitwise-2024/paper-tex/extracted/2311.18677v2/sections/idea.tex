\section{\papername: Prompt token separation on heterogeneous hardware}

To exploit the characteristics of different GPUs, we propose \papername, a system that distributes inferences across heterogeneous hardware.
This may imply running each phase in different hardware.
For example, one could run prompts on a server with H100 GPUs and tokens on A100.

\inigo{Be careful to not lead to hybrid server with some H100s and some A100s, etc}
